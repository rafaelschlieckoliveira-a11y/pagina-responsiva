# pagina-responsiva
# 🌾 AgroTech - Blog de Notícias do Agronegócio

Este projeto é uma plataforma simples de postagens com o tema agronegócio e tecnologia no campo. O layout foi desenvolvido utilizando CSS Flexbox com foco em cards horizontais de largura total.

## 🚀 Desafio CSS Aplicado

No arquivo `style.css`:
- O seletor `article` teve sua propriedade `flex-direction` alterada de `column` para `row`, alinhando imagem, título e texto em linha.
- A propriedade `flex` dos cards foi ajustada para ocupar **100% da largura** da página (`flex: 1 1 100%`).
- Foi aplicada a propriedade `align-self` nas imagens e botões dos cards para alinhar elementos de forma personalizada, quebrando o alinhamento padrão.

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estruturação semântica.
- **CSS3**: Estilização com Flexbox.
- **JavaScript**: Interatividade nos cards.

## 📌 Como Executar

1. Clone o repositório ou baixe os arquivos.
2. Abra o arquivo `index.html` em qualquer navegador.
